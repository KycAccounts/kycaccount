# SilentVault — non-custodial TON wallet Telegram Mini App

Connect a TON wallet (Tonkeeper, MyTonWallet, Telegram's built-in wallet),
view TON + USDT balances, send TON and USDT, receive via address + QR,
and see recent activity — all inside Telegram.

Non-custodial: this app never holds funds, never sees a seed phrase, and
never signs anything itself. Every transaction is approved by the user in
their own wallet.

Launch: hosted on GitHub Pages at
https://kycaccounts.github.io/kycaccount/ and opened from the
@SilentVaultofficialbot bot (BotFather /newapp + /setmenubutton).

See WALLET_SPEC.md for the full spec and security model.
